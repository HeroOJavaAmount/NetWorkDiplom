# Протокол обмена сообщениями сетевого чата

## Общие сведения
- **Транспорт**: TCP.
- **Кодировка**: UTF-8.
- **Разделитель сообщений**: символ перевода строки `\n` (каждое сообщение – отдельная строка).
- **Синхронность**: сервер и клиент обмениваются строками последовательно; клиент читает ответы
- сервера до перехода в режим чата.

## Порядок подключения (аутентификация)

1. **Сервер → Клиент**: `"Login:"`  
   Запрос логина.

2. **Клиент → Сервер**: `<логин>`  
   Произвольная строка (не может быть пустой или `/exit`).

3. **Если логин == `"admin"`**:
    - Сервер → Клиент: `"Password:"`
    - Клиент → Сервер: `<пароль>`
    - Сервер сверяет пароль со значением `admin` из `settings.txt`.
        - При совпадении: Сервер → Клиент: `"STATUS OK"`
        - При несовпадении: Сервер → Клиент: `"STATUS WRONG"` и повтор с шага 1.

4. **Для всех остальных логинов** (не `admin`):
    - Сервер → Клиент: `"STATUS OK"` (пароль не запрашивается).

После получения `"STATUS OK"` клиент переходит в режим чата.

## Режим чата (обмен сообщениями)

- **Сообщения от клиента**: любая строка (кроме служебной команды) отправляется на сервер.
- **Сервер** транслирует (broadcast) сообщение всем подключённым клиентам в формате:  
  `"[<имя_отправителя>]:<текст>"`  
  *Пример*: `"[Alice]: Привет всем!"`
- **Служебные сообщения от сервера** начинаются с префикса `"SERVER:"`.  
  *Примеры*:
    - `"SERVER:Добро пожаловать в чат!"` (при подключении)
    - `"SERVER: Goodbye!"` (при выходе клиента)

## Служебные команды

- **Выход из чата**: клиент отправляет строку `"/exit"`.  
  Сервер отвечает `"SERVER: Goodbye!"`, закрывает соединение и удаляет клиента из списка 
- участников.

## Логирование

- **На сервере**: все события (подключения, отключения, сообщения) записываются в `serverFile.log`
- с временной меткой.
- **На клиенте**: все полученные сообщения (начинающиеся с `[`) записываются в `clientFile.log` 
- с временной меткой.
- **Формат временной метки**: `yyyy-MM-dd HH:mm:ss` (пример: `[2026-06-16 14:30:00]`).

## Расширяемость

Протокол текстовый, что позволяет легко добавлять новые команды (например, `/private`, `/history`) 
без изменения транспортного уровня.
